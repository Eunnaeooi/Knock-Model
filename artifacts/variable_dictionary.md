# 변수 설명서 (중장년 사회적 고립 위험 모델)

> AI 에이전트가 변수 이름을 말로 풀어 설명할 때 참고하는 문서입니다.
> 분석 단위: 행정동 47개 (강남구 22, 춘천시 25) · 기준 노트북: `modeling/Clustering.ipynb`

## 1. 인구축

### HH1_EXPO_5060 — 1-1 중장년 1인 세대 노출도
- **계산식**: (1인 세대 수 ÷ 전체 세대 수) × (50·60대 인구 ÷ 전체 인구)
- **위험 방향**: 값이 클수록 위험 ↑
- **쉬운 말**: 혼자 사는 집이 많으면서 50·60대 주민도 많은 동네인지
- **데이터 출처**: 주민등록 인구(성·연령별) + 주민등록 세대(세대원 수별)

### MALE_SHARE_5060 — 1-2 중장년 남성 비율
- **계산식**: (50대 남성 + 60대 남성) ÷ 50·60대 전체 인구
- **위험 방향**: 값이 클수록 위험 ↑
- **쉬운 말**: 50·60대 주민 가운데 남성이 얼마나 많은지 (중장년 남성이 고립에 더 취약함)
- **데이터 출처**: 주민등록 인구(성·연령별)

### VISIBLE_IDX_50P — 1-3 중장년 생활 노출 지수
- **계산식**: (유동인구 중 5060 비중) ÷ (10세 이상 주민 중 5060 비중)
  - 유동인구 5060 = 50대 + 60세 이상 × (주민 60세 이상 중 60대 비율)
- **위험 방향**: 값이 작을수록 위험 ↑
- **쉬운 말**: 동네에 사는 50·60대가 실제로 거리에 나와 얼마나 눈에 띄는지 (1보다 작으면 사는 사람에 비해 바깥 활동이 적음)
- **데이터 출처**: SKT 유동인구(성·연령별) 2025.7~12 합산 + 주민등록 인구(성·연령별)

## 2. 지역축

### TIME_ENTROPY — 2-1 생활 리듬 다양성
- **계산식**: 시간대별(0~23시) 유동인구 비중 p_h의 엔트로피 = −Σ p_h · log p_h (최댓값 log 24 ≈ 3.178)
- **위험 방향**: 값이 작을수록 위험 ↑
- **쉬운 말**: 하루 종일 고르게 사람이 오가는지, 특정 시간에만 붐비고 나머지는 비어 있는지
- **데이터 출처**: SKT 유동인구(시간대별) 2025.7~12 합산

### POP_DENSITY — 2-2 물리적 밀집도 (인구밀도)
- **계산식**: 총인구 ÷ 행정동 면적(km²) (단, SHAP용 z-score와 최종 모델 z-score에서는 log 변환 후 표준화)
- **위험 방향**: 값이 작을수록 위험 ↑
- **쉬운 말**: 동네에 사람이 얼마나 빽빽하게 사는지 (드물수록 이웃과 마주칠 일이 적음)
- **데이터 출처**: 주민등록 인구(행정동 총인구) + 행정동 면적(EMD_MST)

## 3. 점수·결과 변수

| 코드명 | 보고서용 이름 | 계산식 | 쉬운 말 |
|---|---|---|---|
| `{변수}_Q` | 변수별 단계 점수 | 시군구 안 5분위 → 1~5점 (5 = 가장 위험, 위험 방향으로 뒤집음) | 같은 시·구 안에서 이 동이 몇 등급인지 |
| `POP_SCORE` | 인구축 점수 | 1-1·1-2·1-3 단계 점수의 평균 (1~5) | 사람 쪽 위험이 얼마나 큰지 |
| `REG_SCORE` | 지역축 점수 | 2-1·2-2 단계 점수의 평균 (1~5) | 동네 환경 쪽 위험이 얼마나 큰지 |
| `TOTAL_SCORE` | 종합 점수 | 인구축 점수 + 지역축 점수 (2~10) | 두 위험을 합친 점수 |
| `RISK_LEVEL` | 고립 위험도 5단계 | 47개 동 TOTAL_SCORE 5분위 (5 = 상위 20%) | 이 동이 얼마나 먼저 도와야 하는 곳인지 |
| `GROUP_T` | 군집 유형 | 2D z-score + K-means(K=5) → HH1 / HH2 / HL / LH / LL | 어떤 종류의 위험 동네인지 (첫 글자 = 인구축, 둘째 = 지역축) |
| `POP_5060` | 5060 인구 수 | 50대 + 60대 주민 수 | 같은 단계 안에서 우선순위를 정할 때 쓰는 규모 |

## 4. 축·점수 설명

1. **5분위 점수를 시군구 안에서 매기는 이유**: 강남구와 춘천시는 인구밀도·상권 구조가 크게 달라(춘천 4명/km² ~ 강남 31,000명/km²), 원래 값을 섞어서 매기면 지역 차이가 점수를 지배하기 때문에 각 시군구 안에서 상대 순위로 1~5점을 줍니다. 최종 모델의 군집 입력인 z-score도 같은 이유로 시군구 안에서 표준화합니다.
2. **축 점수 = 변수 점수 평균 (동일 가중)**: 인구축은 3개 변수, 지역축은 2개 변수의 점수를 같은 비중으로 평균합니다. 위험도 5단계와 군집 이름(HH/HL/LH/LL)에는 5분위 단계 점수의 평균(1~5점)을, 최종 모델(K-means, K=5)의 군집 입력에는 시군구 내 z-score의 평균을 씁니다. 가중치를 둘 수치 근거가 없어서 동일 가중으로 했고, 최종 모델 기준으로 인구축을 2배 가중해도 종합 순위상관이 0.971로 거의 변하지 않습니다.
3. **5단계 = 47개 동 전체 TOTAL_SCORE 5분위**: 종합 점수(5분위 인구축 점수 + 지역축 점수)를 시군구 구분 없이 47개 동 전체에서 5분위로 나눠, 상위 20%를 5단계(최우선 개입), 하위 20%를 1단계로 정합니다.
